# Money Mentor 2.0

### AI-Powered Multi-Agent Financial Research & Investment Intelligence Platform

Money Mentor 2.0 is an end-to-end AI-powered financial research platform designed to analyze publicly traded companies from multiple perspectives before generating an investment-oriented research report.

Instead of relying on a single prediction model, the system combines **time-series forecasting, fundamental analysis, SEC filing analysis, recent financial news, retrieval-augmented generation, local LLM reasoning, explainability, and automated evaluation** into a unified LangGraph workflow.

The application provides an interactive Gradio dashboard where users can enter a stock ticker and receive a comprehensive analysis containing price history, next-day LSTM prediction, fundamental metrics, SEC filing information, recent news, AI-generated investment insights, technical explainability, evaluation results, agent execution logs, and a downloadable PDF report.

> **Important:** Money Mentor 2.0 is an educational/research system and is not financial advice. Predictions and recommendations generated by the system should not be treated as a guarantee of future market performance.

---

## Project Overview

Traditional stock-analysis applications often focus on a single dimension of the market, such as technical indicators, financial ratios, or news sentiment.

Money Mentor 2.0 approaches the problem as a **multi-source financial intelligence pipeline**.

For a selected ticker, the system collects historical market data and derives technical indicators, retrieves fundamental company metrics, accesses SEC filing information, gathers recent news, embeds retrieved information into a FAISS vector store, performs LSTM-based next-day price forecasting, and passes the combined context through a locally hosted Qwen2.5-3B-Instruct language model.

The entire process is orchestrated using **LangGraph**, with each analytical responsibility represented as a specialized agent operating over a shared state.

The implementation uses Python 3.11 and is designed to run in Google Colab with GPU support.

## Key Features

### 1. LSTM-Based Stock Price Forecasting

Money Mentor uses a recurrent neural network built with TensorFlow/Keras to perform next-day stock price prediction.

The model uses a 60-day historical sequence and incorporates:

* Closing price
* Trading volume
* 50-day moving average
* RSI
* MACD

The numerical features are normalized using `MinMaxScaler`, and the LSTM architecture contains two recurrent layers followed by dropout and dense layers.

The trained model is cached locally and reused for subsequent analysis of the same ticker.

The system returns:

```text
Current Price
Predicted Price
Expected Percentage Change
Bullish / Bearish Trend
```

---

### 2. Technical Indicator Analysis

Historical market data is retrieved through `yfinance`.

The system derives several technical indicators:

* MA-50
* EMA-20
* RSI
* MACD
* Bollinger Band Upper
* Bollinger Band Lower

These features are used both for analysis and as inputs to the LSTM forecasting pipeline.

---

### 3. Fundamental Analysis

The Fundamental Agent retrieves company-level financial metrics through Yahoo Finance.

The analysis includes:

* Market Capitalization
* P/E Ratio
* Forward P/E
* PEG Ratio
* Return on Equity
* Debt-to-Equity
* Current Ratio
* Profit Margin
* 52-Week High
* 52-Week Low
* Analyst Recommendation

Results are cached to reduce repeated external requests.

---

### 4. SEC EDGAR Filing Intelligence

Money Mentor integrates with the **U.S. SEC EDGAR data infrastructure** to identify recent regulatory filings.

The SEC Agent:

1. Resolves the company's CIK using the SEC company ticker mapping.
2. Retrieves the company's SEC submissions.
3. Identifies recent `10-K` and `10-Q` filings.
4. Extracts filing dates and accession numbers.
5. Stores the resulting summary for downstream analysis.

The implementation explicitly uses SEC endpoints and a custom User-Agent header.

> **Current scope:** The SEC module is designed around U.S.-listed companies and SEC filings. It should not be interpreted as an equivalent filing system for Indian companies regulated by SEBI.

---

### 5. Financial News Intelligence

The News Agent retrieves recent ticker-related news through Yahoo Finance and extracts the latest headlines and publishers.

The retrieved news becomes part of the shared analytical context and is subsequently passed to the RAG and Investment Advisor stages.

---

### 6. Retrieval-Augmented Generation

Money Mentor includes a lightweight RAG pipeline using:

**BAAI BGE embeddings + FAISS**

The system combines SEC filing summaries and recent news into a document collection, generates embeddings using `BAAI/bge-small-en-v1.5`, and stores them in a FAISS vector index.

This creates a retrieval layer that can provide financial information to downstream AI reasoning components.

---

### 7. Local LLM Financial Reasoning

Instead of relying entirely on a hosted proprietary LLM API, Money Mentor loads:

**Qwen/Qwen2.5-3B-Instruct**

using Hugging Face Transformers.

When CUDA is available, the implementation enables 4-bit quantization through BitsAndBytes to reduce memory requirements.

The LLM is used for:

* Investment report generation
* Technical explanation
* Report evaluation
* Interactive company-specific chat

---

### 8. LangGraph Multi-Agent Architecture

The core orchestration layer is implemented using **LangGraph**.

A shared `MoneyMentorState` carries information between specialized agents.

The state contains:

```text
ticker
stock_data
prediction
fundamentals
sec_data
news_data
rag_docs
investment_report
explainability
evaluation
logs
```

The current workflow consists of:

```text
Prediction Agent
       ↓
Fundamental Agent
       ↓
SEC Agent
       ↓
News Agent
       ↓
RAG Agent
       ↓
Investment Advisor Agent
       ↓
Explainability Agent
       ↓
Evaluation Agent
       ↓
Supervisor / Workflow Complete
```

The graph is constructed using LangGraph's `StateGraph`, with each analytical component represented as a node.

## Explainability Layer

Money Mentor does not simply output a predicted price.

The Explainability Agent examines the prediction together with technical indicators such as:

```text
RSI
MACD
MA-50
```

The system then asks the local language model to provide a concise interpretation of the technical momentum.

The explainability state stores both generated textual reasoning and numerical indicator values.

This makes the system more useful as a research assistant because users can inspect some of the technical context behind the model output instead of receiving only a numerical prediction.

---

## Automated Evaluation

After generating the investment report, the Evaluation Agent performs a separate review of the generated report.

It is instructed to identify:

* Potential hallucinations
* Logical flaws
* Issues in the investment report

The evaluation output is stored in the shared state together with a trust-score field.

> Note: The current implementation assigns the displayed trust score as `95/100` rather than extracting a dynamically calculated score from the evaluator response. This is an implementation limitation and should not be interpreted as a validated model-quality metric.

---

## Automated PDF Reporting

After analysis is completed, Money Mentor generates a PDF report containing:

* Ticker
* Generation timestamp
* Predicted price
* Percentage change
* Predicted trend
* AI investment report

The report is generated using ReportLab and made available through the Gradio interface.

The chat interface uses the previously generated investment report as context for the local Qwen model.

Example questions:


## Why Multi-Agent Architecture?

The system separates financial analysis into specialized responsibilities instead of placing all logic inside one large function.

This architecture provides several benefits.

**Modularity:** Each analytical capability can be independently modified or replaced.

**Separation of concerns:** Market prediction, fundamentals, SEC information, news, RAG, explanation, and evaluation have distinct responsibilities.

**Shared state:** LangGraph allows the agents to exchange structured analytical information through `MoneyMentorState`.

**Traceability:** Agent execution logs record which stage of the workflow is running.

**Extensibility:** Additional agents such as risk analysis, portfolio optimization, sentiment analysis, valuation, or compliance can be incorporated into the graph.

## Current Limitations

Money Mentor 2.0 is a research prototype and has several limitations that should be understood before using it for serious financial analysis.

### Prediction limitations

The LSTM predicts the next-day price using historical market features. Financial markets are affected by macroeconomic events, geopolitical developments, company announcements, liquidity, market structure, and many other variables that are not fully represented in this model.

Therefore, a predicted bullish or bearish trend should not be interpreted as a reliable forecast of future returns.

### SEC coverage

The current SEC integration uses the U.S. SEC EDGAR infrastructure and therefore primarily supports companies covered by the SEC.

### News coverage

The current implementation retrieves a limited number of recent headlines through Yahoo Finance rather than building a comprehensive news corpus.

### RAG implementation

The current RAG stage indexes the SEC summary and recent news documents into FAISS. It is a lightweight retrieval layer rather than a large-scale production document retrieval system.

### Evaluation score

The displayed trust score is currently hard-coded as `95/100`, while the evaluator's textual critique is generated dynamically. Consequently, the score should not be interpreted as a statistically validated confidence metric.

### Model training

The current LSTM is trained for only a small number of epochs and does not implement a rigorous walk-forward validation or backtesting framework.

### Investment recommendation

The generated recommendation is an AI-generated research output and should not be treated as professional financial advice.
